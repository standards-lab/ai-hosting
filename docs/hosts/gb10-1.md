# gb10-1

This is the descriptor of the first GB10 workstation, which a survey and a measure read to reach the
host and judge what they find there ([the upgrade convention](../upgrades.md)). Every other fact
about the host comes from the probe a survey takes.

## SSH short name

`gb10-1`

## Alias

`agent`, from the gb10 class's profile. The gateway's config is the home of which host serves
which alias ([config.template.yaml](../../compose/agentgateway/config.template.yaml)).

## Load target

The `agent` row's `[rows.load]` table in the [gb10 profile](../../classes/gb10/profile.toml).

## Run noise

The agent row's 12 sessions of S-agent sessions, on vLLM v0.34.0 and kernel 7.0.0-1025-nvidia,
each run from a restarted row ([agent-sessions](../findings/agent.md#agent-sessions),
[agent-noise](../findings/agent.md#agent-noise)):

- **Within-session**: 0.76% on the total output throughput, 109.20 and 110.03 tokens a second, the
  figure the verdict reads; the ITL median spreads 1.81%, 94.30 and 92.62 ms.
- **Across-days**: not measured.
