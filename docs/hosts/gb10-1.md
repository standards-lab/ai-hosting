# gb10-1

The descriptor of the first GB10 workstation, which a survey and a measure read to reach the host
and judge what they find there ([the upgrade convention](../upgrades.md)). Every other fact about
the host comes from the probe a survey takes.

## SSH short name

`gb10-1`

## Alias

`agent`, from the gb10 class's profile. The gateway's config is the home of which host serves
which alias ([config.template.yaml](../../compose/agentgateway/config.template.yaml)).

## Load target

The `agent` row's `[rows.load]` table in the [gb10 profile](../../classes/gb10/profile.toml).

## Run noise

Not measured on vLLM. A measure that needs it runs the incumbent's peak level again
([the upgrade convention](../upgrades.md#the-verdict)).

## Watch items

- [agentgateway concurrency cap per key](../watch.md#agentgateway-concurrency-cap-per-key): a bulk
  key's streams share the agent row's batch with the interactive keys until the gateway can cap
  them.
