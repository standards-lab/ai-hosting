# gb10-2

This is the descriptor of the second GB10 workstation, which a survey and a measure read to reach
the host and judge what they find there ([the upgrade convention](../upgrades.md)). Every other fact
about the host comes from the probe a survey takes. The host also runs the gateway's compose stack:
Torii, the workspace's agentgateway deployment ([the gateway](../gateway.md)).

## SSH short name

`gb10-2`

## Alias

`vision`, from the gb10 class's profile. The gateway's config is the home of which host serves
which alias ([config.template.yaml](../../compose/torii/config.template.yaml)).

## Load target

The `vision` row's `[rows.load]` table in the [gb10 profile](../../classes/gb10/profile.toml).

## Run noise

The vision row's 32 streams of docinfer's dense pages, its throughput peak, on vLLM v0.34.0 and
kernel 7.0.0-1025-nvidia, each run alone from a restarted row, on the second-half rate the row's
peak is read on ([dense-1120-high](../findings/vision.md#dense-1120-high),
[dense-noise-32](../findings/vision.md#dense-noise-32)):

- **Within-session**: 1.5%, 13.40 and 13.60 images a minute, the first at fraction 0.40 and the
  second at the row's committed 0.55, cap 32 and queue limit 64; one request more or less in the
  level's second half moves the rate by about 1.5%.
- **Across-days**: not measured.
